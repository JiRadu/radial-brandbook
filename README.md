# Radial Cons — Brandbook

Identitatea vizuală și de comunicare a **Radial Cons SRL** (atelier de confecții metalice, Târgoviște, din 1999), pentru oferte, website și postări Instagram / TikTok / Facebook.

> **Atelier mic. Precizie de oțel.** — *Hai să construim ceva solid.*

## Pentru AI (ChatGPT, Claude, Gemini)

- **Un singur fișier cu tot:** [`BRANDBOOK-COMPLET.md`](BRANDBOOK-COMPLET.md) — atașează-l într-o conversație sau într-un proiect.
- **Prompt gata de lipit:** [`brandbook/04-prompt-ai.md`](brandbook/04-prompt-ai.md) — caseta de text se copiază în instrucțiunile asistentului.
- **Valori exacte pentru cod:** [`tokens.json`](tokens.json) și [`tokens.css`](tokens.css).
