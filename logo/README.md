# Logo

Fișierele oficiale ale logo-ului Radial Cons. Fiecare variantă există în **SVG** (vector: site, print, orice mărime) și **PNG** transparent (Word, Canva, social media).

| Fișier | Culori | Folosire |
| --- | --- | --- |
| radialcons-logo-orizontal-color | raze Bronz `#B8712A`→`#E8A13E`, R Auriu `#F0A038`, text gradient auriu→bronz | varianta principală, pe alb, crem sau negru |
| radialcons-logo-orizontal-alb | tot alb `#FFFFFF` | pe fotografii și fundaluri închise |
| radialcons-logo-orizontal-negru | tot `#14110E` | print monocrom, ștampile, gravură |
| radialcons-simbol-color | ca mai sus, fără text | poză de profil, favicon, colț de postare |
| radialcons-simbol-alb / -negru | o singură culoare | watermark, gravură laser, fundaluri dificile |

Reguli: spațiu liber minim = înălțimea literei R; lățime minimă 120 px (logo orizontal) / 32 px (simbol); nu se recolorează, nu se deformează, nu se adaugă efecte. Fișierele sunt o redesenare vectorială după logo-ul de pe pagina de Facebook — dacă există fișierul original de la designer, acela are prioritate.
